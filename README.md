# AR家具配置

お部屋の床に、家具と同じ大きさの箱を実寸で置いて、収まりや圧迫感を確かめるブラウザARアプリです。

- 対応: Android の Chrome(WebXR)。Galaxy Z Flip8 を想定。
- 使い方: ページを開き「ARを開始」→ 床を映す → 家具を選んで「ここに置く」。
- 操作: 1本指でなぞると移動、2本指でひねると回転、パネルで寸法・色の変更と削除。
- 方針: 見た目の再現ではなく寸法の確認に絞るため、家具は半透明の箱で表示します。
- カメラ映像は端末内だけで処理し、外部へは送信しません。

構成: `index.html`(画面)/ `app.js`(AR処理)/ `lib/`(three.js)
